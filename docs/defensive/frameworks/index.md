# Frameworks

Security frameworks help organize how defenders understand attacks, adversary behavior, intrusion stages, and threat intelligence.

## Topics

- **MITRE ATT&CK** — Adversary tactics, techniques, and procedures used to map real-world attacks.
- **Cyber Kill Chain** — A staged model for understanding how attacks progress from reconnaissance to actions on objectives.
- **Unified Kill Chain** — An expanded intrusion model that covers modern attack paths.
- **Diamond Model** — A threat intelligence model based on adversary, capability, infrastructure, and victim relationships.
