# Operations

---

## Executive Summary

Operations covers the practical techniques used during and after exploitation to move files, route traffic, and access systems that are not directly reachable.

These skills support post-exploitation, internal enumeration, lateral movement preparation, and controlled testing inside restricted environments.

## Topics

- **File Transfers** — Moving tools, payloads, scripts, logs, and collected evidence between systems.
- **Pivoting and Tunneling** — Routing traffic through compromised hosts to reach internal networks and hidden services.

## Focus Areas

| Area | Purpose |
|---|---|
| File movement | Transfer tools, scripts, payloads, and evidence |
| Uploads and downloads | Move files to and from Linux and Windows targets |
| Protected transfers | Encrypt sensitive data before moving it |
| Port forwarding | Expose internal services through a tunnel |
| SOCKS proxying | Route multiple tools through a compromised host |
| Internal access | Reach networks that are not directly exposed |
