# Web

Web fundamentals explain how websites and web applications work, from browser requests to front-end logic and database-backed functionality.

## Topics

- **How the Web Works** — HTTP, requests and responses, web servers, front-end and back-end components.
- **JavaScript Essentials** — Core JavaScript concepts, DOM interaction, client-side logic, and security risks.
- **SQL Fundamentals** — Relational databases, queries, tables, and the basics needed to understand SQL injection.
