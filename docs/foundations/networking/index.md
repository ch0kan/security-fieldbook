# Networking

Networking is the foundation of how systems communicate. This section covers the core concepts needed to understand traffic flow, protocols, addressing, subnetting, and basic cryptography.

## Topics

- **Network Fundamentals** — OSI model, packets, frames, network types, and core communication concepts.
- **Protocols** — DNS, DHCP, HTTP, TCP, UDP, and other common network services.
- **Subnetting** — IP addressing, subnet masks, CIDR, and network calculation basics.
- **Cryptography** — Encryption, hashing, keys, certificates, and secure communication basics.
