# Identity and Access

Identity is the foundation of enterprise security. It defines who users, computers, and services are, how they authenticate, and what resources they are allowed to access.

This section covers the core identity concepts used across Windows and Active Directory environments, including authentication protocols, access control, domains, groups, and trust relationships.

## Topics

- Active Directory fundamentals
- Users, computers, groups, and organizational units
- Kerberos and NetNTLM authentication
- Domain trees, forests, and trusts
- Windows access control concepts
