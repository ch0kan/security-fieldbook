# Cheatsheets

---

## Executive Summary

Cheatsheets are compact field references for commands, syntax, ports, tools, and investigation shortcuts.

These pages are meant for quick lookup during labs, assessments, analysis, and troubleshooting. They should stay short, practical, and command-focused.

## Sections

- **Core** — Common ports, networking references, encoding, and hashing.
- **Operating Systems** — Linux, Windows, and PowerShell command references.
- **Reconnaissance** — Nmap, DNS, subdomains, and OSINT.
- **Web** — Burp Suite, web requests, and SQLMap.
- **Exploitation** — Metasploit, shells, file transfers, and tunneling.
- **Credentials** — Hydra and password cracking references.
- **Defensive** — Log hunting, Splunk queries, and detection quick references.

## Usage Notes

- Replace placeholder values such as `TARGET_IP`, `DOMAIN`, `USERNAME`, and `PORT`.
- Validate commands in a lab before using them in a real environment.
- Prefer safe, authorized, and documented testing workflows.
- Keep commands updated as tools and syntax change.
